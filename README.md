# Karpathy Exercises

This repository collects study notebooks based on Andrej Karpathy's "Neural Networks: Zero to Hero" series.

The `micrograd/` folder focuses on building a tiny autograd engine and working through the backpropagation exercises. The `makemore/` folder explores character-level language modeling, starting with bigrams and moving into trigram and related training exercises.

## Zero to Hero lessons

These notebooks are inspired by the early lessons in Karpathy's series, especially:

1. `micrograd` - the scalar autograd engine lesson.
2. `makemore` - the bigram language model lesson.
3. Follow-up makemore lessons that extend the model with training and optimization exercises.

## Contents

- `micrograd/` - autograd and backpropagation exercises.
- `makemore/` - language model notebooks and data files.
